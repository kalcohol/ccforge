Implementation And Contract
---------------------------
backport/cpp26/hive/detail/bounded_sort.hpp is an independent C++20 kernel
using textbook depth-limited quicksort, bounded three-way partitioning,
small-range insertion and an internal heap fallback. Each scan has explicit
index bounds; a partition excludes a nonempty middle and leaves strictly
smaller sides. The smaller side recurses and the larger side iterates.

The production insertion threshold is 24 and depth credit is twice
floor(log2(N)). Byte exchanges and insertion rotations neither construct T
nor invoke its assignment/swap overloads. The kernel requires a live array
of trivially copyable objects, allocates nothing, and calls no library sort
or heap algorithm. Only the supplied comparator can throw. Comparisons
must return or throw and must not modify the values/storage; inconsistent
comparison answers do not control index bounds or termination.

Both Hive scratch paths use this kernel. Small eligible values use the
unchanged <=16-byte trivial-copy gate, allocator-rebound scratch and memcpy
writeback. Already ordered scratch returns before writeback. Other values use
an allocator-rebound address/index table and the existing ADL-swap permutation
cycles. Fancy allocation handles, count limits and construction rollback remain
intact. No stack small-N container scratch was introduced; the kernel has only
bounded local exchange storage and logarithmic recursion.

All container comparisons finish before writeback/permutation. D1 remains
unchanged: after an exception the container is valid, size is unchanged and
there are no leaks; element order and individual values are unspecified.
Existing stronger comparator-exception observations were not weakened.
S-I9 is an internally validated property under the stated comparator boundary,
not a new public promise in docs/backports/hive.md. No third-party sorting or
container implementation source was inspected, imported or benchmarked by the
implementer. External similarity review is still a separate reviewer action.

plus one million distinct sampled relations for each n=5..8. Every relation
runs in three modes: 4066067 relations, 12198201 sort invocations. It also
checks all 598445 ordered equality rank words through n=8, each in three
modes and two directions: 3590670 invocations. Counters verify actual
partition, insertion and heap-fallback execution.

Hive V6 covers both paths, two block-limit settings, six sizes, dense/sparse
layouts and eight comparator variants: 384 matrix cells. Throwing cells have
baseline, selected throw positions and recovery invocations; 384 is not an
invocation count. L1/L2 add assignment-template, multifield and 16-byte
differentials, every-comparison exception sweeps and allocation-failure sweeps.
Structure, addresses, full payloads and allocation ledgers are checked.
